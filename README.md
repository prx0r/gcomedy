# The Geometry of Comedy

**A book.** Tymoczko proved music is geometry — chords as points in orbifold space, voice leading as geodesics, tonality as limited macroharmony around a center. This book proves the same for comedy.

## Thesis

A laugh is a geodesic. Setup establishes a point in idea-space. Punch is the minimal move to violation. Callback is a harmonic return — the same chord voiced differently. Rasa (the nine Indian aesthetic flavors) is the tonality. Rhythm is the time axis, and laughter synchrony is neural entrainment. Delivery is the voicing — how the same joke moves differently for different players.

Comedy isn't "funny stuff." It's a structured space with metric, topology, and conservation laws. Once you can measure the distance between a setup and its punch, you can compose.

## The nine rasas (from library/rasa)

| Rasa | Flavor | Comedy angle |
|---|---|---|
| Shringara | erotic | romantic comedy, the setup of desire |
| Hasya | **comic** | the target — laughter itself |
| Karuna | compassionate | tragicomedy, the laugh that costs |
| Raudra | furious | roast, the aggressive comic |
| Veera | heroic | the underdog bit, triumphant punch |
| Bhayanaka | terrifying | horror-comedy, the transgressive edge |
| Bibhatsa | odious | gross-out, the violation that still charms |
| Adbhuta | wondrous | absurdist, surreal, the "wait what" beat |
| Shanta | peaceful | deadpan, the anti-comic hold |

Comedy is hasya *inflected* by the other eight. Roast = hasya + raudra. Absurdism = hasya + adbhuta. This is the tonality map — comedy never lives in one rasa alone.
