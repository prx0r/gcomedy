# Comedic Functions, Defined Geometrically

> Draft 2026-10-18. Companion to Ch.3 (formal geometry) and Ch.4 (violation
> geometry). Where Ch.3 defines the SPACE and Ch.4 defines the BOUNDARIES,
> this chapter defines the MOVES: what each comedic function IS as a
> trajectory, with its timing signature measured where data exists.
> Method: Tymoczko Ch.7 (functional harmony) is the template — there, chords
> have functions (tonic/dominant/subdominant) by virtue of what they DO in a
> progression, not what they ARE. Same here.

## 0. What a function is

A musical function (tonic, dominant) is not a chord — it is a role a chord
plays: stabilize, depart, demand return. Likewise a comedic function is not
a bit of text — it is a role a beat plays in a trajectory: establish,
intensify, violate, extend, return, close. Functions are defined by
(shape of path) + (timing signature) + (effect on the archive). Six
functions cover the observed repertoire: SETUP, ESCALATE, PUNCH, TAG,
CALLBACK, BUTTON.

## 1. SETUP — establish the platform

- **Trajectory:** slow drift within a small neighborhood of joke-space.
  Builds weight on the dominant reading without moving far. Low
  reinterpretation distance per second, extended duration.
- **Timing:** regular cadence, short gaps (baseline ~29ms inter-word in our
  corpora — rapid, unbroken delivery). The setup must NOT contain long
  silences: silence this early reads as error, not tension (no accrued
  weight to suspend).
- **Geometry:** lays the A of AAB. Two similar events minimum (Rozin):
  the platform needs two points to define its direction.
- **Ñāṇavīra reading:** installs the shared priority ordering — declares
  what is 'this'. Everything after is measured against it.

## 2. ESCALATE — intensify along the platform

- **Trajectory:** repeated AAB cycles at rising intensity (list of 3,
  rule-of-three, heightening). Each cycle re-traverses nearby ground at
  higher V or higher energy. Direction same, magnitude growing.
- **Timing:** accelerating cadence OR lengthening holds between cycles —
  either the words come faster or the gaps grow. Both raise the
  prediction slope (Huron tension scales with uncertainty × stakes × time).
- **Geometry:** the path spirals outward from the platform center without
  leaving the macroharmony (same rasa, same key). Escalation that modulates
  (changes rasa mid-list) breaks the function — it becomes a new setup.
- **Failure mode:** escalation without direction (louder, not higher) =
  intensity-without-target from the overshoot table.

## 3. PUNCH — minimal jump to a disjoint reading

- **Trajectory:** the shortest path from the setup neighborhood to a point
  outside it that remains connected by the LM (logical mechanism). Small
  displacement, large consequence — one relabeling, whole world changes.
  Our data: punch length r = −0.32 with score; word overlap ≈ 0 with score
  (the move is in model-space, not word-space).
- **Timing (TWO MODES — measured 2026-10-18, n=44 laughs, 5 KT sets + Louis):**
  - **Overlap mode (36/44, 82%):** laughter ignites mid-utterance (≤0.05s
    gap). No silence. The punch's tail IS the trigger; the room can't wait.
    Typical of fast rooms, hot streaks, tags.
  - **Gap mode (8/44, 18%):** 1.86–5.08s of silence, THEN the laugh. The
    hold-then-snap trajectory (pause 1.4–2× baseline, delivery 1.48× after).
    Typical of big swings, dark material, closers.
  - The two modes are different instruments, not different qualities: gap
    mode suspends weight (gain adaptation, Zwicker logic), overlap mode
    rides momentum. A set needs both the way music needs legato and
    staccato. Louis holds belong to gap mode; Normand's snap belongs to
    overlap.
- **Geometry:** the jump must land inside the viable manifold (Ch.4 fence:
  benign basin + legit TA + commitment). Same distance, different landing
  zone = funny vs offensive. Distance without habitability predicts nothing
  (violation alone r = −0.02).
- **Bhartṛhari reading:** sphoṭa — the whole sentence reorganizes in one
  moment. The punch doesn't add information; it re-weights the past.

## 4. TAG — extend along the punch direction

- **Trajectory:** cardinality increase (C-operation): additional beats
  departing from the punch point in the same direction. Each tag travels
  less far than the punch (diminishing returns geometrically enforced —
  second tag must be shorter/sharper or it reads as new setup).
- **Timing:** overlap mode almost always (tags ride the laugh's tail;
  a held silence before a tag kills it — nothing accrued to suspend).
- **Geometry:** tags explore the neighborhood the punch opened. Best tags
  (per trial data: L2 self-target discovers) re-aim the TA while holding
  SO — same opposition, new victim, preferably self.
- **Economy:** first tag pays ~full, subsequent decay. Pure repetition
  (same words) pays zero — no new path, no new pleasure (callback economy
  §callback).

## 5. CALLBACK — return path, transposed

- **Trajectory:** path from current point BACK to an earlier archive point,
  revoiced (transposed: same SO+LM, new SI/TA). First invocation ×1.5
  (recognition pleasure = the return path itself, a higher-order thing per
  Ñāṇavīra operations). Second invocation half. Pure repeat zero.
- **Timing:** needs a beat of silence before it (the room must retrieve —
  Bergson habit-memory + recollective-memory both fire). Callbacks rushed
  inside overlap mode misfire; they need a mini-gap for retrieval.
- **Geometry:** near-center jokes get called back most (Ch.3 prediction 3:
  SO-ambiguity correlates with callback degree — ambiguous points have the
  most return paths). The callback graph's degree distribution IS the
  night's shape; champion = maximal coverage, minimal backtracking.
- **Iser reading:** the return reactivates every audience member's private
  fillings simultaneously — recognition of one's own co-creation, changed
  by everything since. Pleasure = self-recognition at one remove.

## 6. BUTTON — close to center

- **Trajectory:** path back to the persona key (macroharmony center).
  Resolves open trajectories, discharges residual tension, returns priority
  to the default ordering. Closer/outro/tag-button: all are centering moves.
- **Timing:** decelerating cadence, final hold, then release (applause =
  the room's own snap). The button's silence AFTER it belongs to the room,
  not the comic — do not step on it.
- **Geometry:** the set is a closed trajectory iff it ends near where it
  began in (SO, rasa, key) coordinates with higher archive mass. Open sets
  (ending far from center) feel unfinished regardless of joke quality —
  this is a geometric judgment, not a content one.

## 7. The six functions as a complete system

Every observed beat in the corpora (154 scored bits, 44 laugh-timed events,
 Louis/Norm analyses) classifies into exactly one function. Transition
rules (all observed, none stipulated):
SETUP → ESCALATE → PUNCH → TAG* → {BUTTON | SETUP} ; CALLBACK may fire
from any post-PUNCH state back to any archive point; BUTTON closes.
No beat skips SETUP (cold opens are setups with zero prior — the 10s black
is the setup: framework with no things). PUNCH never precedes its SETUP
(the P-constraint, Ch.3 prediction 1).

## 8. Functions × rasa (the tonality each function favors)

| Function | Native rasa | Why |
|---|---|---|
| SETUP | śānta/śṛṅgāra (peaceful/loving) | Stable platform needs low arousal |
| ESCALATE | vīra (heroic) | Rising energy, triumph-over-material |
| PUNCH | adbhuta (wondrous) | The snap IS wonder (camatkāra micro-event) |
| TAG | hāsya (comic) | Pure play inside opened space |
| CALLBACK | karuṇa-tinged hāsya | Recognition + time = warmth inside laughter |
| BUTTON | śānta (peaceful) | Return to rest |

A set's rasa arc (e.g., śānta → vīra → adbhuta → hāsya → śānta) is its
macroharmonic journey — the same object as Tymoczko's key areas, at the
evening's timescale.
