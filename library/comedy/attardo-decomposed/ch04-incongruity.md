# Chapter 4: Incongruity and Resolution

## Incongruity definition

Attardo defines incongruity as **divergence from expectations**. This is broader than "surprise" — it includes:
- Semantic incongruity (meaning mismatch)
- Script incongruity (world mismatch)
- Tonal incongruity (register mismatch)

**Our mapping:** punch surprise = the semantic/script incongruity. The DPV framework's "temporal + semantic violation" is a special case where the incongruity is timed.

## Resolution types (Attardo's taxonomy)

| Type | Description | Our mapping |
|---|---|---|
| **Full resolution** | The incongruity is completely explained | Classic setup→punch→reframe |
| **Partial resolution** | Some incongruity remains (absurdist humor) | Lock, surrealist comedy |
| **Foregrounded incongruity** | The incongruity is the point | Anti-jokes (Norm) |
| **Backgrounded incongruity** | Resolution is smooth, surprise is in the timing | Louis confessions |

**Key insight:** not all funny things fully resolve. Partial resolution is why absurdism works — the incongruity REMAINS, but the audience finds it funny anyway. (Maps to BV: violation + benign coexisting.)

## The Isotopy Disjunction Model (IDM)

Attardo's model for linear joke processing:

1. **Setup** establishes an "isotopy" — a semantic field that directs interpretation
2. **Punchline** disjoins the isotopy — forces a different reading
3. **Resolution** is the listener re-interpreting the setup under the new isotopy

**Example (Louis Monopoly):**
- Setup isotopy: "parenting is hard" (six-year-old learning to lose)
- Punchline disjoins: "to handle HER" (the daughter is the problem, not the losing)
- Resolution: re-read the premise — this is about the FATHER's inability to handle the daughter's emotional development

**Maps to our:** DPV framework's "setup builds a prediction model, punch violates it." The isotopy IS the prediction model. The disjunction IS the temporal+semantic violation.

## Linear organization (Ch 4.3)

Attardo shows jokes have a LINEAR structure:
- Setup builds expectation (direction A)
- Punchline redirects (direction B)
- The redirect must use material ALREADY in the setup (misdirection, not withholding)

**The key rule:** the punch must use material the audience already has. If the punch introduces new information ("well, you didn't tell me that"), the joke fails. This is why:
- Setup must establish the platform (Rock's premise rule)
- Punch must be the MINIMAL move to a disjoint reading (our "shortest path")
- Tags extend in the same direction (diminishing returns)

## Foregrounded vs backgrounded incongruity

- **Foregrounded:** the incongruity IS the joke (anti-jokes, absurdism, Norm's moth)
- **Backgrounded:** resolution is smooth, surprise is in the timing (Louis confessions, Rock premises)

Our series covers both: foregrounded in "misdirection" and "where-jokes-come-from," backgrounded in "punch" and "timing."
