# MISDIRECTION MICRO-TECHNIQUES — good vs bad, banked

## GOOD MISDIRECTION vs BAD
| Good | Bad |
|---|---|
| Assumption identified before writing (named who/what/where) | Vague hope audience assumes something (unexamined) |
| Connector flippable (one part does double duty) | No connector (setup and punch merely adjacent) |
| Obvious angle deliberately bypassed (mediocrity weaponized) | Obvious angle taken (room saw it coming, polite laugh) |
| Sleep on it (assumption lists的现象 marinate) | First-draft misdirect shipped (shallowest flip) |
| Mediocrity mocked, not taken (make fun of the obvious take) | Obvious take + shrug (room already thought of it) |

## Bank
1. **Story1/Story2/connector (Dean).** Write the imagined scene, name the load-bearing assumption (who/what/where), find the flippable part, write Story 2. Mechanical, repeatable.
2. **Weaponize mediocrity (beastwoom).** Take your predictable punch, brainstorm alts that circumvent it or mock the obvious angle itself. Don't elevate mediocrity — abandon it and joke about the abandonment.
3. **Assumption lists + sleep (presidentender).** Write ALL assumptions a setup creates. Sleep. Return: write the statement aligned with facts but subverting every listed assumption.
4. **Obvious-take audit.** For each punch ask: would the room predict this? If yes, it's a placeholder — generate 5 alts before staging.
5. **Connector stress test.** Remove the connector: do setup and punch become unrelated? If they still connect, the connector wasn't load-bearing — find the real one.
6. **Sixth-option check (Locke).** List 5 places the premise could go. Discard all 5. The sixth is the bit. If you can't list 5, premise too thin.
7. **Mediocrity burial.** Bury the obvious take INSIDE the bit as a decoy (character suggests it, gets shot down), then land the real one. Double misdirection.
8. **Energy misdirect (Mr Cee).** Positive energy + negative reveal (or reverse). Buy-in first with tone, flip with content.
9. **No-telegraph scan.** "You're never gonna believe..." = announcing the flip. Cut all announcements; let energy do the buying.
10. **Sleep rule.** No misdirect ships same-day. Assumption lists need overnight marination minimum. Rush = shallow flips.
