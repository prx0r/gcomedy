# RHYTHM — series-wide beat grid + per-episode signatures

> Measured 2026-10-18 from locked ESSAYs (narration words per beat slot;
> wpm includes clip/pauses occupancy — low narration wpm = clip-dense).
> Template: README §2 (14-min, 840s). Method: beat headers → durations;
> words counted after stripping cards/cues/notes.

## 1. The shared skeleton (all 15 episodes)

Every episode runs the same 12-slot grid (14:00 total):

```
EXPOSITION (0:00–2:30, 18%) — engine 0:30 / proof 1:00 / thesis 1:00
DEVELOPMENT (2:30–11:30, 64%) — lens 2:00 / persona 1:30 / case 3:00 /
  case-coda 1:00 / specimen 0:45 / specimen-coda 0:45
RECAPITULATION (11:30–14:00, 18%) — failure 1:15 / universal 0:45 / close 0:30
```

Sonata proportions (18/64/18). The arc breathes the same way everywhere:
fast open → slow middle (clips carry) → fast close. Mean densities:
exposition ~96 wpm, development ~72 wpm, recap ~91 wpm. The trough IS the
method — development slots carry 3–11 clip cues each while narration drops
to ~60–70 wpm. Any episode whose development runs hot (>85) is a wall of
voice; any whose exposition runs cold (<80) opens flat.

## 3. Drift list (accidental, normalize)

1. **Beat names (status/target).** Both use SPECIFIC THESIS / CASE PAYOFF /
   SPECIMEN TURN / HUMAN UNIVERSAL / CLOSE where the house grid says
   THESIS+VOCAB / case-coda / specimen-coda / UNIVERSAL / CLOSE+HOOK.
   Same slots, different labels — normalize to house names (content unchanged).
2. **Pause exposition 2:45.** Intentional (level-5 cold open). Logged, not drift.
3. **Tags middle hole (57 wpm).** Structural, from the STACK cut — see §4.
4. **Setup density (136/94/92).** Hottest in all three sections — see §4.
5. **Target close pile-up (121 wpm).** See §4.

## 4. Recommendations (in order)

1. **Setup: cut ~150 words or add 2 clip cues.** Easiest cuts: LENS
   Monopoly-Christmas passage (already covered in Ep 0 case) and the THEFT
   coda's pre-installed list (renter's rage, deposits, 2 AM emails — one
   example carries it). Target: expo ≤115, dev ≤85.
2. **Tags: restore ~150 words.** Either reinstate a measured tag-run beat
   (needs the DATA.md deposit first) or extend the gymnastics coda with the
   headliner-vs-opener economics cut from STACK (qualitative, no numbers).
3. **Target close: move the butt-ledger to a gold card** (~60 words out of
   voice) or cut the ledger beat to MICRO-TECHNIQUES. Target: recap ≤100.
4. **Status/target beat names → house grid** (cosmetic, 10 headers).
5. **Escalation engine +20 words of dare** (coldest open; one more
   surprising-four-times line before the thesis lands).
6. **Delivery clip audit at pull** (11 cues × ≤15s = 165s max — fits, but
   only just; any excerpt creep breaks the middle).

## 5. What varies correctly (do not normalize)

- Pause's 2:45 exposition (silence IS the content).
- Origin's 3-clip count (talk carries the coda).
- Punch/escalation flat arcs (compression subjects should feel locked).
- Button's accelerating close, target's verdict pile-up shape (trimmed, kept).
- Per-episode coda topics (theft, rescue, misjudge, re-weight — the series'
  memory lives in the codas; the grid is the same so the codas can differ).
