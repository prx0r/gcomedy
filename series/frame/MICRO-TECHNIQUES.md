# FRAME MICRO-TECHNIQUES — good vs bad, banked

## GOOD FRAME vs BAD
| Good | Bad |
|---|---|
| Real/fictional status clear (room knows the game) | Frame confusion (is this true? irrelevant question burning attention) |
| Unreliable narrator flagged (persona openly heightened) | Stealth fiction (room feels lied to on discovery) |
| Sincerity doctrine held (commit to the frame's rules) | Winking (performer signals superiority to own frame) |
| Frame breaks deliberate (named, timed, paid off) | Accidental breaks (corpse, riff that punctures with no return) |
| One frame per bit (nested frames labeled) | Frame soup (real story, fake aside, real confession — unmarked) |

## Bank
1. **Declare the game (Acaster).** Fictitious premises announced by exaggeration itself (undercover cop = openly false). Room co-signs knowingly.
2. **Unreliable on purpose (Lee).** Failed callback as trojan horse: wreckage smuggles revelation. Engineered, never accidental.
3. **Sincerity inside fiction.** Commit to frame rules absolutely once set (Acaster cop-show logic held for full specials). Winking bankrupts belief.
4. **Honesty-vs-oversharing gate (TrainingVivid4768).** Structured jokes about real pain = comedy. Unstructured pain-sharing = therapy with witnesses. Frame the pain or cut it.
5. **Nested frames labeled.** Story-within-story needs signposts (voice shift, lighting cue, "meanwhile"). Unmarked nesting = confusion.
6. **Breaks pay rent.** Any frame break must deliver ≥ the laugh it costs. Corpsing that earns nothing is debt.
7. **Red-dress proof.** True rejected, fiction bought: belief irrelevant, co-signing everything. Optimize for buy-in, never truth.
8. **Stealth ban.** No hidden fiction. If discovery would anger the room, announce upfront. Trust compounds; gotchas spend it.
9. **Frame per bit, reviewed.** List each bit's frame + transitions weekly. Soup gets ladled into bowls or cut.
10. **Coda frame.** Final bit's frame = the show's frame (circular). Leave the room in the world you built, then close it.
