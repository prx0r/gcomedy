# TARGET MICRO-TECHNIQUES — good vs bad, banked

## GOOD TARGET vs BAD
| Good | Bad |
|---|---|
| Butt named before writing (powerful/self/species) | Butt discovered after (who was that on?) |
| Assumed target = intended target (room assigns correctly) | Room assigns wrong target (setup subject ≠ intended butt) |
| One butt per joke (clean liability) | Diffuse butt (everyone slightly insulted, nobody laughing) |
| Self-target confessional (+0.2 distance, earnest) | Self-target shield (performative, deflecting) |
| Victim never the butt (veto respected) | Punch-down dressed as edge (fails every gate) |

## Bank
1. **Name the butt first (VIOLATION.md §4).** Powerful/self/species — decided BEFORE writing. Never discovered after.
2. **Subject-position audit (Socratopia Ch.18).** Whoever the setup holds is who the punch happens to. Check: does the held subject match the intended butt? If not, rewrite the setup, not the punch.
3. **Persona steers aim.** Same line from fixer vs victim mouths points opposite ways. Know which mouth you're in.
4. **One butt rule.** Diffuse blame = diffuse laughs. If two candidates, pick one; make the other a tag.
5. **Confessional +0.2.** Self-target with earnest frame buys distance. Without earnestness it's just complaining.
6. **Powerful > self > species > (never victim).** Target hierarchy in descending safety. Victim = veto, always.
7. **Intensity-without-target check.** Loud violation, unclear butt = WARN. Name it or cut it (edge_trial pattern).
8. **Room-as-butt sparingly.** Roast-the-room works once per set max (shared enemy must be outside next time or it's bullying).
9. **Sacred-price list.** Care + sanctity read darkest (clean language still max-dark). Price accordingly: dark targets need long setups.
10. **Butt ledger.** List every joke's butt weekly. Patterns reveal cowardice (always safe targets) or cruelty (always victims).
