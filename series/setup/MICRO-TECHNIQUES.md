## GOOD SETUP vs BAD SETUP (the video's spine)

| Good | Bad |
|---|---|
| Declares world in ≤25 words | Explains, apologizes, backstories |
| Hides where it's going (misdirection) | Telegraphs the punch ("you'll never believe...") |
| One attitude throughout (SREP: consumer, not victim) | Attitude shifts mid-setup |
| Funnest word last (trim rule) | Punch word buried mid-sentence |
| No backstory unless it builds tension or adds a laugh | Autobiography before platform |
| Ends on a complete, believable false world | Ends on a wink (room sees the strings) |

## Micro-technique bank (each = 20–40s demoable)

1. **Truth→Angle (Workshop pipeline).** Boring fact in one line → list its
   quirks → state your attitude + cartoon exaggeration. ("Vending machine
   always breaks" → eats money, glass teases → "steals more than Vegas.")
2. **SREP (Bennett).** Setup hides destination → Reveal (the actual comic
   idea) → Escalate → Payoff. Regan UPS: facts only, never states his
   inadequacy — the gap does the work. Bridges bus stop: attitude as
   consumer ("I'm a sucker for a bargain").
3. **Broken assumptions (CreativeStandUp).** Every sentence: who/what/where/
   when/why/how, explicit (green) vs assumed (red). Punch shifts exactly
   ONE assumption. Good setup: exactly one load-bearing assumption. Bad:
   three at once (room can't track) or zero (nothing to shift).
4. **Story1/Story2 + connector (Dean).** Name the scene in the audience's
   mind, the target assumption, the flippable connector, the new story.
   Demo on one KT setup live.
5. **Third thought (Jeselnik).** First thought obvious, second thought
   worked-for, third thought one step removed (never-would-have-thought).
   3 jokes/day mornings + 50 pages reading. Measure by reaction SIZE
   (huge laugh or cut it).
6. **Seinfeld compression.** Closer jokes together = bigger laughs (the
   roll). First line funny immediately. Connective tissue like jigsaw;
   shave letters/syllables to fit (songwriting). Biggest laugh at END.
7. **Write what you know (Gervais).** Ordinary made extraordinary beats
   extraordinary made up. Real detail (tea, lavender, mold) > invented
   spectacle. Setup fuel comes from noticing, not imagining.
8. **No-telegraph rule (Mr Cee via Chortle).** Never announce the turn
   ("you're never gonna believe..."). Positive energy + negative reveal
   (or reverse) — buy-in first, flip second.
9. **Act-out spectrum (Regan↔Bridges).** Full physical embodiment vs
   minimal voice/gesture. Same function (make the world present), two
   settings. Pick per bit, never mid-bit.
10. **Repeat-the-premise (Rock).** Restate the platform mid-chunk. Campfire
    rule: feed it or it goes out. Demo: same chunk with/without restatement.

11. **Corley formula.** Truth statement → association lists (nouns, verbs,
    adjectives — consonant-heavy words punch harder) → emotion finish ("I
    [love/hate/fear] X because ___") → pick format → brevity → never put
    punch words in the setup. Mechanical, unglamorous, works.
12. **Pipeline check (Workshop).** Truth (boring fact, one line) →
    Attributes (quirks list) → Angle (attitude + cartoon exaggeration) →
    Combo (Truth→Exaggeration→Misdirection / Sarcasm→Rule-of-3 /
    Understatement→Absurd / Persona→Flip→Tag) → Trim (halve it, funniest
    word last). Run every setup through all five gates before staging.
