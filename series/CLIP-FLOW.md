# CLIP FLOW — assembly format for all videos

> No essay writing. Fluid organization of clips + techniques. Per beat:
> EXPLAIN (reddit/theory source, ≤2 sentences) → SHOW (clip, timestamped)
> → ANALYZE (brief, gold voice: what just happened + one measured number).
> Repeat. The video is a playlist with connective tissue, not a script
> with illustrations.

## Beat template (copy per beat)

```
### BEAT n — <technique>
EXPLAIN: <source: reddit/theory/paper, 1-2 sentences max>
SHOW: <videoId t=start-end> — <what happens>
ANALYZE: <gold voice, 2-3 sentences: mechanism named + one number>
```

## Rules
- Explain ≤2 sentences. If it needs three, it belongs in production notes.
- Every SHOW has videoId + timestamps + embed URL (from MICRO-CLIPS.md
  or resources CLIPS.md). No untimestamped clips.
- Every ANALYZE carries exactly one number (pause seconds, wpm, ratio,
  count). Numbers are the analysis.
- Order beats by the 10-beat arc (STRUCTURE.md), but beats are clip-led:
  if no clip demonstrates it, the beat doesn't exist.
- Theory names never spoken. Reddit handles/lingo OK ("r/Standup calls
  this...") — craft voices, not papers.
