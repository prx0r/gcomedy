# FUNDAMENTALS OF COMEDY — series bible + copyable template

> 8 videos, one per function. Magnum-opus styling (track bar + glyphs,
> Funnier palette, gold measurements). Human comics only — no fictional
> freaks as examples. Every claim lands on measured data or a sourced clip.

## The template (copy this folder structure per video)

```
series/<function>/
  STRUCTURE.md   — beat-by-beat blueprint (this file's §2, filled in)
  RHYTHM.md      — timing map: section durations, cut density, pause plan, BPM
  CLIPS.md       — clip assignments (comic, bit, timestamps, clearance)
  VOICEOVER.md   — full speakable script (160 WPM budget)
  DATA.md        — measurements backing every on-screen number
```

## §1. Rhythm style (all videos — non-negotiable)

Derived from Tymoczko's five components, restated as production law:

1. **Centricity — one thesis sentence.** Stated in the first 30s, orbited
   by every section, restated in the close. No section may introduce a
   second thesis. (The tonal center.)
2. **Limited macroharmony — vocabulary reservoir.** Defined term list per
   video (≤10 terms), on screen in the description. No new jargon past the
   halfway mark. New words late = modulation without preparation.
3. **Conjunct transitions — minimal leaps.** Each section opens with the
   previous section's last idea. Shared terms between adjacent sections ≥1.
   (Voice-leading economy: small moves between meaningful harmonies.)
4. **Harmonic consistency — one visual language.** Track bar + glyphs from
   video 1 onward. Same palette, same type, same overlay grammar. A viewer
   mid-series should read new glyphs without narration.
5. **Consonance — resolve before opening.** Every tension opened in a
   section resolves inside it — except ONE series hook per video (the
   next-video question, stated in the last 60s).
6. **Timing grid.** Hook 0:00–0:30 (thesis + proof-of-value). Sections
   3–5 min each. Cut density 3–6s normal, 1–2s high-energy, 8–12s held
   moments (max 2 per video). Pause discipline: 2–3s after key lines only.
   Section changes on musical bar lines (fixed BPM bed per video).

## §2. Beat order (gold 11-beat arc, tightened for 18–22 min)

```
1. ENGINE NAMED (0:00–0:30) — the function in one line + thesis sentence
2. PROOF (0:30–1:30) — one clip showing the function working, unexplained
3. SPECIFIC THESIS (1:30–2:30) — what this video claims + vocabulary list
4. CROSS-DOMAIN LENS (2:30–5:00) — the device defined via music/film FIRST
5. PERSONA LAYER (5:00–8:00) — one comic's relationship to this function
6. CASE STUDY (8:00–14:00) — one bit, chronological, clip IS text, overlays fire
7. SECOND SPECIMEN (14:00–17:00) — same function, different comic, different handling
8. FAILURE MODE (17:00–19:00) — the function done wrong (overshoot taxonomy)
9. HUMAN UNIVERSAL (19:00–20:30) — mechanism → claim about being alive
10. CLOSE (20:30–22:00) — thesis restated + series hook (next function)
```

Word budget: 18–22 min × 160 WPM = 2,880–3,520 words spoken.

## §3. Data discipline (all videos)

- Every on-screen number measured (pause durations, word counts, rates)
  or sourced (paper, timestamp, transcript).
- Human comics only for examples. Generated bits (BRAKEFORCE/roster)
  usable ONLY as labeled deck illustrations, never as specimens.
- No verbatim copyrighted text in repo (bit_id + scores + timestamps only).
  Clips = fair-use excerpts ≤15s, transformative commentary, credited.
- Wilson before crowns: no "funniest/best" claims under n≥30.
