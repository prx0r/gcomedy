# VOICE MICRO-TECHNIQUES — good vs bad, banked

## GOOD VOICE vs BAD
| Good | Bad |
|---|---|
| Consistent (no joke contradicts another) | Contradictory (ladies-man + wife-guy in one set = trust death) |
| Describable in one sentence (word-of-mouth test) | Indescribable (fan can't explain you = no referrals) |
| Close to self, heightened (packaging matches box) | Fabricated register (audience senses costume) |
| Stable across years, evolving (Seinfeld 10-20% churn) | Reinvented nightly (no compounding identity) |
| Honest throughout the set (hofstetter rule) | Voice shifts for easy laughs (impressions of other comics) |

## Bank
1. **Consistency audit (hofstetter).** List every biographical claim in the set. Any contradiction = cut one. Trust compounds; contradiction bankrupts.
2. **One-sentence test.** "A [X] who [Y]." If fans can't say it, neither can bookers. Write it, test it on civilians, refine quarterly.
3. **Start close to self (afatcomic).** Heighten, don't invent. Years reveal which heightenings stick; fabricated registers shed under pressure.
4. **Internal-voice mic (OjibweNomad).** Give the stage your actual inner monologue, turned up. Turn it OFF offstage (sustainability + material accrual).
5. **Seinfeld churn.** Replace 10-20% yearly, keep the core. Voice evolves (alive) without reinvention (no compounding loss).
6. **Clever→personal migration (Cross).** Wit opens rooms; confession keeps them. Plan the migration deliberately (year 2-3 typical), don't drift.
7. **Packaging check (Comedyfight).** Voice = packaging, self = box. Match them. Mismatch reads instantly and kills connection before jokes start.
8. **No-contradiction table read.** Read set straight through hunting self-contradictions (stances, biographies, attitudes). One table read monthly.
9. **Word-of-mouth drill.** After shows ask fans to describe you in a sentence. Collect answers; converge voice toward the best ones.
10. **Register floor.** Define your minimum register (clean? dark? absurd?). Never book below it for money; floor violations haunt tape forever.
