# FUNCTION COLORS — canonical, all videos, thumbnails, accents

> Locked 2026-10-18. Every function owns one hue. Overlays, subtitles,
> glyphs, thumbnails, and accents all draw from this table. No exceptions.

| Function | Color | Hex | Meaning |
|---|---|---|---|
| Setup | Blue | `#3B82F6` | Foundation, platform, calm water before the break |
| Escalation | Orange | `#F97316` | Rising heat, the climb |
| Punch | Red | `#E8102E` | Violation, snap (Funnier brand red — locked) |
| Tags | Rose | `#FB7185` | Echo of punch, fading with each hit |
| Callback | Gold | `#F5C76B` | Return, recognition, precious metal |
| Button | Green | `#22C55E` | Closure, locked, resolved |
| Premise | Violet | `#8B5CF6` | Ground of grounds, the world-plate everything stands on |
| Pause | White | `#F8FAFC` | Absence made visible; silence with weight |

## Rules
- Background always `#07070a`. Text `#f3f1ec`. Muted `#8d8b93`.
- Subtitles: setup lines blue, punch lines red — from Episode 0 onward,
  every clip, every video.
- Track-bar glyphs use function colors; pause timer digits stay gold
  (measurement color, not function color).
- Thumbnails: black bg + function color dominant + white title. Series
  recognition at a glance: blue video = setup, red = punch, etc.
- Tags diminish visually: first tag full rose, each next -20% opacity.
- Callbacks: first return full gold, second return half-alpha (matches
  the ×1.5/half/zero economy).
- Never use red for anything but punch/violation. Never use gold for
  anything but callbacks/measurements/theory labels.
