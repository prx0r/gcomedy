# TAGS MICRO-TECHNIQUES — good vs bad, banked

> Sources: Dean tag pipeline, Louis Monopoly tags, Gulman state-abbreviation
> stacks, Normand machine-gun runs, decay economics (ours).

## GOOD TAG vs BAD (the video's spine)

| Good | Bad |
|---|---|
| Assumes punch's world (zero rebuild) | Re-establishes context (pays setup prices) |
| New fracture, same world | Restates punch (no new fracture = no laugh) |
| Shorter than the punch | Same length or longer (stalls the decay) |
| Lands inside the decay window (~4s) | Arrives after the room sealed back up |
| Diminishing series (each smaller/faster) | Flat series (same size = competing with punch) |

## Micro-technique bank

1. **Trust the world.** No setup words in a tag. Fragments only ("going
   down hard") — the punch taught the language, tags speak it.
2. **New fracture rule.** Each tag must break something unbroken. Audit:
   list what each tag fractures; duplicates die in rehearsal.
3. **Diminishing returns by design.** Shorter + faster each time. The decay
   curve IS the rhythm (18 words → 6 → 3 typical).
4. **Decay-window timing.** ~4s of laugh-energy post-punch. Tags inside it
   ride free; tags after it pay full price. Count it on the waveform.
5. **Re-aim, don't repeat (Gulman).** Same world, new victim/angle per tag.
   State abbreviations: 50 states, one platform, endless re-aims.
6. **Speed-stacking (Normand).** Tags overlapping the laugh, each shorter —
   rhythm does half the work. Requires machine-gun delivery; slow comics
   use depth instead (Louis excavator: darker each tag).
7. **Excavator tags (Louis).** Go darker once the world's frame is fully
   installed (benign frame at max = safest moment for max violation).
8. **Tag gymnastics.** Rare: tag reframes the punch retroactively. New
   fracture PLUS new past. Guard for closers, not middles.
9. **Know the count.** Two tags standard, three pushing, four+ needs a
   structural reason (stack record, finale). Announce nothing; feel the window.
10. **Stop on top.** End the chain while a tag is still working. The
    withheld next tag becomes audience imagination (free laugh, zero words).

11. **POV-shift tags (Meltzer/Dean).** Tag by changing WHO speaks:
    Narrator→Self→Character→Audience→Object. Gaffigan: 21 POV shifts in
    2.5 minutes. Act-outs ARE tags — embodiment instead of wording.
    Physical tags extend the laugh without new laughs (act out the punch's
    consequences while the room is still going).
12. **Switchback tags (Martin).** Shatter NEW assumptions your own punch
    created ("what happens next if my punch is true?"). Chain them:
    three switchbacks = the nice-girl cat shape. Each tag breaks the last
    tag's world, not the original setup's.
