# EPISODE 0 — WHAT IS A JOKE?

> Series opener. Cold open: "What is a joke? Your life." Then iconic jokes,
> then the geometric decomposition: every joke taken apart into blocks that
> snap together into bits, chunks, sets. The series videos ARE the blocks —
> this episode hands you the box.

## The definitions (glossary cards, stated once, used forever)

- **One-liner:** setup + punch in a single sentence. (Hedberg, Wright,
  Youngman. Paraprosdokian = its Greek backbone.)
- **Joke:** atomic unit. One setup, one punch, one laugh point.
- **Bit:** premise + several jokes + tags. Minutes long.
- **Chunk:** bits on one topic, ~10–15 min. (Wikipedia ladder.)
- **Set:** the whole performance.
- **Premise / setup / punch / tag / callback / button:** the six moves —
  one line each here, one video each later.

## Beats (~13 min)

**1. COLD OPEN (0:00–0:45).** Black. "What is a joke?" [2s] "Your life."
Then ONE iconic joke, whole, 15 seconds — Hedberg one-liner. Laugh. Freeze.

**2. DECOMPOSE (0:45–2:30).** The same joke again — but now subtitles run
underneath in two colors: setup in BLUE, punch in RED, switching exactly
where the turn happens. Then the film says it once: "A joke is made up of
a setup [blue flash] and a punchline [red flash + punch SFX]." That color
grammar is now law — every clip in every video in this series runs blue
setup / red punch subtitles. No exceptions.

**3. TWO CLEAR EXAMPLES (2:30–5:00).** Same treatment, twice more: one
story joke (Louis — blue holds long, red snaps), one fast one-liner (Vine
or Carr — blue/red almost touching). Three jokes total, three color
switches, the pattern unmissable by the third. Then the Lego beat: blocks
snap apart on screen — blue setup block, red punch block. Tags snap on
like studs. A bit is a plate of jokes. A chunk is stacked plates. A set is
the whole build.

**4. THE LADDER (3:00–4:00).** One-liner (sentence) → joke (setup+punch) →
bit (premise + jokes + tags) → chunk (bits + topic) → set (the night).
Glossary cards fan out, one per rung. "Learn the blocks once and every
video from here recognizes itself." Promise: no definitions ever again.
Only pointing.

**5. THREE GOLD CLIPS (4:00–10:00).** The episode contains the whole
series. Three exemplar bits, each carrying premise, setup, pause, punch,
tag, button — in three variant forms. Full track-bar + glyph treatment
from the first frame (the visual grammar debuts here, Café-ready):
  - **LOUIS (storyteller variant):** long premise buried in narrative,
    confession punch, excavator tags, verdict button. Setup blue runs
    minutes; punch red snaps; tags stack diminishing.
  - **NORM (minimalist variant):** thin premise, moth-style anti-climax
    (the punch that refuses to punch), deadpan button. Same six functions,
    opposite economy — proves the functions aren't styles.
  - **HEDBERG/VINE (density variant):** pure one-liners back to back, no
    tags needed, premise implied per line. The minimal bit: premise so
    thin it's one shared assumption, buttons every fifteen seconds.
  Each clip: blue/red subtitles throughout, function glyphs firing on the
  track bar, pause timers on holds. After the third: "Three bits. Same six
  moves. Different universes."

**6. LENS (10:00–11:00, music first, compressed).** Motif = one-liner,
phrase = joke, movement = bit, symphony = hour. Beethoven's Fifth, four
notes. Same compositional logic (Wikipedia ladder cited on screen).

**7. SERIES MAP (11:00–12:00).** The box lid: 15 blocks, each with its
episode title. "Each one gets its own episode. You just watched the core
moves three times over — now we take them apart one by one, then perform
them, then turn the invisible forces." Hook into
Premise: "We start at the beginning. The world everything lives in."

**8. FAILURE MODE (12:00–12:45).** Tags standalone (die without their
punch's world), stories with no laugh points (travelogues), premises
mistaken for jokes. Name the unit wrong, misdiagnose every failure.

**9. CLOSE (12:45–13:30).** "What is a joke? Your life — in eleven
seconds, on purpose." Black. Glossary cards persist in description.

## Rhythm map
Cold open 45s / decompose 105s / ladder 60s / 3 clips 360s / lens 60s /
map 60s / failure 45s / close 45s = 13 min + pauses. Track-bar + glyph
grammar debuts in the 3-clip section and never changes.
