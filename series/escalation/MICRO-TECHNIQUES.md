# ESCALATION MICRO-TECHNIQUES — good vs bad, banked

> Sources: UCB heightening/game, McKeague triple, Carlin planet bit,
> Normand moth, Socratopia list mechanics. Craft sources, no papers.

## GOOD ESCALATION vs BAD (the video's spine)

| Good | Bad |
|---|---|
| Same direction, bigger steps | Sideways (new idea instead of bigger same idea) |
| Logic preserved (world intact) | World breaks mid-climb (rules change to force bigger) |
| Third beat transforms, doesn't repeat | Third beat = first beat louder |
| Stops while curve climbs (leave one in tank) | Rides it into silence (fourth beat that begs) |
| Each pass earns its size (detail added) | Size asserted, not earned ("and then it was HUGE") |

## Micro-technique bank

1. **Heighten the game (UCB).** Find first unusual thing → bear hug it in
   ONE direction (heaven or heck, never both). Demo on moth joke: dread
   deepens each pass, never widens.
2. **Rule-of-three arithmetic.** Items 1-2 install category (ordinary on
   purpose), item 3 breaks it. Test failing thirds by asking which category
   the first two installed — fix the install, not the break.
3. **Escalation list (4+, Socratopia).** Each item confirms + raises; break
   comes AFTER the last item reinterpreting the whole climb. Opposite
   machine from rule-of-three — never mix them mid-list.
4. **Two is enough (shared context).** Airports/dentists/phones: room
   supplies item one, start at item two. Don't build what they walked in with.
5. **Carlin counts.** 18 phenomena in 46 words vs 2 things in 10 words —
   ratio IS the joke (4.6:1 sweet spot; <3:1 thin, >6:1 indulgent).
6. **Velocity vs volume.** Escalate speed (Normand snap) OR size (Carlin
   pile) — pick one per bit. Both at once reads as panic.
7. **The lean rule.** Each pass must add one new concrete detail (not just
   adjectives). Detail is what makes bigger believable.
8. **Stop-one-early.** End the climb while the room wants one more. The
   withheld fourth beat becomes audience imagination (free escalation).
9. **Callback as ceiling.** Cap an escalation by returning to item one,
   revoiced (Mulaney dogs/horses shape). Closes the ladder into a loop.
10. **Napier's niceness check.** Reluctance to push = the usual failure.
    Ask: "what's the most extreme honest version?" Then perform that.

## Books/voices (1 quote each max)
Carlin (autobiography, sledgehammer vs rapier), Normand (podcast process),

11. **Mullen extremes.** State opinion + exact opposite. Take both to
    extremes. More extreme. Combine — mock both sides. Add three tags +
    punchline. Escalation by opposition instead of magnitude: the climb
    splits in two directions at once.
