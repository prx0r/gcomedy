# EXEMPLAR SEQUENCES — complete bits for full-function deconstruction

> 5 sequences + the Monopoly bit. Each contains the complete function arc:
> SETUP → ESCALATE → PUNCH → TAG → CALLBACK → BUTTON.
> These are the theoretical specimens the video deconstructs throughout.

## How to use in the video

The episode runs these sequences as its spine:
1. Play the full sequence raw (audience sees the whole arc)
2. Replay with function overlays firing (SETUP label, ESCALATE counter, PUNCH pause timer, TAG marker, CALLBACK arrow, BUTTON bar)
3. The narrator names each function as it fires
4. Second specimen = same function, different comic, different handling
