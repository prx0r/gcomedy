## HOW TO USE

For each episode:
1. Read `series/resources/<topic>/CLIPS.md` → pick primary + specimen clips
2. Read `CRAFT_TALK.md` → comedian process quotes
3. Read `DATA.md` → on-screen numbers with provenance
4. Read `THEORY.md` → source citations
5. Cross-reference `series/<topic>/MICRO-TECHNIQUES.md` (other agent's bank)
6. For agent training: convert to MICRO-SCHEMA entries (good/bad observables)
