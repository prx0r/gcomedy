# TIMING MICRO-TECHNIQUES (whole-set) — good vs bad, banked

> Distinct from PAUSE video (the hold instrument). This is set-level temporal structure.

## GOOD TIMING vs BAD
| Good | Bad |
|---|---|
| Pace varies by chunk (fast/slow contrast) | One tempo all night (room entrains, then sleeps) |
| Peaks placed (big bits on energy highs) | Random order (closer energy mid-set wasted) |
| Breathers after peaks (room recovers) | Peak-chasing (every bit max effort, no dynamics) |
| Metronome inside bits, rubato between | Metronome everywhere (mechanical) or nowhere (formless) |
| Set shortens in rewrite, never lengthens | Added material dilutes pace (new minutes, same laughs) |

## Bank
1. **Chunk tempo map.** Mark each chunk fast/slow before ordering. Alternate deliberately; never two slows adjacent.
2. **Peak placement.** Biggest bit where energy peaks (~70% mark), not at end (closer = button, different job).
3. **Breather rule.** After any 8/10 bit, one easy chuckle bit. Recovery is pacing, not filler.
4. **Rubato between, metronome within.** Bits run tight; transitions breathe. The contrast IS the rhythm.
5. **Slow-down pass.** First rewrite of any set: cut 10% of words, add 10% pauses. Speed comes from density, not pace.
6. **Energy-match returns.** See delivery #8. Timing includes re-entry.
7. **TAMS metronome.** Fix inter-onset intervals tour-wide; let laughs vary. Composed constancy, emergent variance.
8. **Light discipline.** Hit the light: be ON the closer, not starting it. Plan backwards from out-time.
9. **Record + clock.** Timestamp every laugh for 3 sets. The timing map emerges; taste follows data.
10. **Kill the darling pause.** Any pause kept for habit, not weight, gets cut. Audit quarterly.
