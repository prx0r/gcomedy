# AGENT START HERE

New box, new agent? Run this:

```bash
git clone https://github.com/prx0r/gcomedy.git && cd gcomedy
bash setup.sh   # clones 21 tool repos, installs runtimes, verifies
```

Then read in order: `README.md` (stack map) → `essay1/FILM-STRUCTURE.md`
(the film) → `essay1/film/STUDIO.md` (the edit loop) →
`essay1/TOOLS-VERDICT.md` (what's proven vs parked).

## What you get
- `essay1/film/screenplay.md` + `shots.json` — source of truth, edit these
- `essay1/film/laptop-film/` — HyperFrames project (lint clean, renders 20s in ~30s)
- `essay1/renders/laptop-v1/` — first filmed prototype MP4 + stills + generator
- `essay1/skills/` — 4 proven skills with process notes
- `essay1/tools/` — gitlinks pinning exact tool versions (setup.sh re-clones)
